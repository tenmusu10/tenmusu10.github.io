# tenmusu10.github.io

アプリの公開用ページ（GitHub Pages）。

| パス | 内容 |
|---|---|
| `metabo-burst/about.html` | 紹介ページ（スクショ・説明・ブラウザで遊ぶ・Google Play）。Play へのボタンは `release.json` で出る |
| `metabo-burst/press.html` | プレスキット（基本情報・紹介文・スクショ・ロゴ・連絡先）。素材は `metabo-burst/press/`（zip も）。配信日と Play へのリンクは `release.json` で出る |
| `metabo-burst/guidelines.html` | 配信・動画ガイドライン（実況・収益化OK）。Play の URL は `release.json` で出る |
| `metabo-burst/release.json` | Play で一般公開しているか・公開日。**手で直さない**：metabo-burst の Actions「Play 公開の切り替え」が書き換え、web.yml がここに置く |
| `metabo-burst/img/` | 紹介ページ用画像（metabo-burst の store/ を縮小したもの） |
| `metabo-burst/privacy.html` | メタボリック・バーストのプライバシーポリシー（元は tenmusu10/metabo-burst の `privacy.html`） |
| `app-ads.txt` | AdMob の販売者確認用（AdMob 登録後に追加） |
